# Vinaya Web

Landing page plus the methodology surfaces (The Harness, Docs, Install, Studio) for Vinaya. Part of the [AttaLabs](../../../README.md) ecosystem.

**Domain:** vinaya.attalabs.dev

"Vinaya" means "discipline" or "the rules of conduct" in Pali.

## Landing hero

The landing page opens with the **harness hero** (`(site)/_components/hero-canvas/VinayaHeroEmblem`):
an accent wireframe "harness" that builds itself — ring segments draw on, robotic columns
extend from the ring and gripper-clamp the central `main` sphere, electricity draws across
the gaps — with a main-centered fabric shock wave (Vāda's `AIACanvas` ClosingPulse). It sits
above the existing hero; its **See More** button scrolls down to the rest of the page.
