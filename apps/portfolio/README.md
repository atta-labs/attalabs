# Portfolio

Daniel Estevez's one-page animated portfolio — the story, the career, and every product shipping out of Atta Labs.

Next.js 16 + Tailwind v4 + `@atta/ui` (shadcn-based libraries), themed from Sanity (`portfolioConfig` in the central `attalabs` project), animated with `motion`.

```bash
bun run dev:portfolio     # http://localhost:3009
bun run build:portfolio
```

Page copy lives in `web/src/content/portfolio.ts`.
