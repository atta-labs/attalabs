**Context:** The session that scoped the `aeg-ui-v1` iteration (AEG Studio) surfaced four model gaps while planning a second, concurrent iteration. Per the Principal's standing theory (governance must govern; detail written into the model makes every agent behave more identically), each was written into the model in real time rather than parked. This entry consolidates that batch for the ratification trail; the prose lives in the named docs. Companion to **AEG-product D-001** (the two-product Studio/Portal split), logged in `apps/aeg/specs/aeg-decisions.md`.

**Decision:** Adopt as permanent model rules (all already written into the named docs):

1. **Label vocabulary (`aeg-root/state-machine.md` §14).** Single source of truth for labels: a closed set — `tier:{0,1,3}`, `aeg:blocked`, `needs:{execution,strategy,principal}-input`, `needs:brief-correction`, `override:docs`. Governing principle: **a label exists only where the forge can't say it natively.** Three mandatory shapes: always-mandatory (`tier:*`, exactly one per task), conditional-mandatory (present-when-true AND removed-when-false — `aeg:blocked`, `needs:*`), and the one optional escape hatch (`override:docs`). Two easy-to-get-wrong rules made explicit: **project is a field, not a label**; **tier is a field-on-PR-body (binding source of truth) plus a synced label-on-Issue** (Planner sets the label at cut as a plan-time estimate; the field wins on conflict; the Archivist asserts label == field).

2. **Iteration lifecycle (`aeg-root/iterations/README.md` §11).** planned → active → complete → archived. Completed iterations move to `aeg-root/iterations/completed/<name>.md` and are **never deleted** — the Planner's rationale is durable forensic history (D-042). The Archivist sets the single `Lifecycle:` marker at close-out; this is the one sanctioned exception to "no execution metadata in the iteration file," because the forge has no native "whole iteration done" fact ("complete" is itself derived from all linked PRs merged — the marker is a convenience flag written once, not a maintained status).

3. **Cross-iteration concurrency (`aeg-root/iterations/README.md` §5, §11).** No hard cap on concurrent iterations. The conflict rule **binds across concurrent iterations** — a collision domain is global, so two tasks in different iterations that touch the same package conflict exactly as siblings would. Disjoint iterations (no shared collision domain) run fully parallel. The second concurrent iteration's readiness gate must read the active iterations' `Project(s)` / collision domains and either confirm disjointness or declare the cross-iteration serialization. Concurrency is bounded by collision-domain disjointness and Principal attention, not by a number.

4. **Conversational protocol (`aeg-root/aeg-manual-flow.md` §4.5 + `aeg-root/roles/planner.md`).** A shared, model-level protocol for how every conversational role talks to the Principal — legibility is a governance property; a silent flow is ungovernable. The shared spine: announce the role on entry; name the stages and always say which one you're in; narrate the load-bearing reads and their conclusions; move little-by-little and confirm before proceeding; reflect back before committing anything durable; **signal stage completion clearly every time** (especially the final "planning complete — next is dispatch, whose move it is"); and be clear about durability (everything committed is on `main`/permanent, and a `Lock: NO` decision is as committed as a `Lock: YES` one — the lock flag governs future editability, not existence). Kept light — signposting, not verbosity. Shared spine; each role specializes it. The **Planner** specialization is written first (`roles/planner.md`); Brief Author, Developer, and Reviewer specializations are explicitly future work.

**Alternatives rejected:**
- Park these as candidates and ratify later: rejected — governance must govern; detail written into the model in real time makes every agent behave more identically.
- An open / freeform label set: rejected — drift; a label only exists where the forge can't say it natively, and an open set re-introduces a second source of truth for facts the model already homes (status, project, priority).
- Delete completed iterations once merged: rejected — the Planner's rationale is the most valuable durable thing the plan produced; `completed/` is an archive, not a graveyard (D-042).
- Document the conversational protocol only inside `planner.md`: rejected by the Principal — it is a model-wide concept; it belongs in the flow doc as a shared spine, with per-role specializations pointing at it.
