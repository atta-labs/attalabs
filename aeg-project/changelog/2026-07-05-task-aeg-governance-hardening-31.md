## July 5, 2026 — Task 31: Vercel shallow-clone fix + permission gap + CI job consolidation

### AEG / Vāda / Herald / Atta / AttaLabs

- **Vercel shallow-clone fix (#395 item 1)** — Vercel's build container checks out a shallow (depth-10), single-branch clone, so `refs/heads/main` doesn't exist on preview deploys and `turbo-ignore --fallback=main` (task 22, #353) errored with "a ref or SHA is invalid" and silently failed open — building everything, the exact behavior task 22 meant to eliminate. All four `vercel.json` `ignoreCommand`s now prepend two bounded, tolerant fetches — `git fetch --deepen=100 origin` (reach the deploy branch's fork point) and `git fetch --depth=100 origin main:main` (materialize `main`; refuses harmlessly on production main-deploys where it already exists) — each wrapped in `(… || true)` so any failure degrades to today's fail-open, never worse. `--fallback=main` itself is untouched. Proven in a local depth-10 single-branch clone (before: `main` unresolvable; after: resolves, merge-base found, `turbo-ignore` correctly skips); full proof requires a real Vercel deployment and is recorded as a post-merge expectation.
- **`direct-main-push-detection` permission gap (#395 item 2)** — the job's `permissions:` block (task 24, #364) was missing `pull-requests: read`, which the commits→pulls association API requires, so the detection 403'd (`Resource not accessible by integration`) on every real `main` push. Scope added; the job is also now runnable via `workflow_dispatch` so it can be verified on demand instead of waiting for the next real push.
- **9-job PR-gate consolidation (#395 item 3, formerly task 34/#404)** — the repo hit GitHub's free-tier 2,000 Actions-minutes/month cap in 5 days: 9 sub-30s gate jobs across 5 workflow files each billed a full rounded-up minute per push (~9 minutes of pure checkout/setup overhead). `Closes #N`, Coherence oracle, Single-plan-PR guard, Runtime Test Plan, Tier-appropriate documentation gate, Biome lint/format, Commit-message format, Forbidden colors, and Brief Validation now run as 9 sequential steps of one **"AEG gate suite"** job in `forge-lifecycle.yml` — one checkout/setup/install, per-step failure visibility preserved (`!cancelled()` guards, no `continue-on-error`), original per-check event scopes preserved (`edited` → Test Plan only; `labeled`/`unlabeled` → docs gate only). `verify-docs.yml`, `verify-test-plan.yml`, `conventions.yml` deleted; `brief-validation` removed from `archivist.yml`. `ci.yml`'s `typecheck-and-tests` and `claude-code-review.yml` deliberately untouched. Same gates, same strictness — packaging only.
- **Surface:** 4× `vercel.json`, `.github/workflows/{forge-lifecycle,archivist}.yml` (+3 workflow files deleted), `aeg-root/enforcement.md` (ring-1 packaging note, ring-2 detection row, 4 pairing-matrix rows), this changelog entry. Tier 1. Closes #395.
