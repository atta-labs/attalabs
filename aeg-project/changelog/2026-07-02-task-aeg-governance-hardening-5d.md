## July 2, 2026 — Post-merge Archivist automation + plan-PR Closes guard (D-077)

### AEG
- **aeg-governance-hardening task 5d (#309)** — Closes two confirmed governance gaps identified in this session's retrospective. First, the per-task Archivist specified by `roles/archivist.md` never ran mechanically — it was skipped on essentially every merged task PR in this repo's history, causing 3 of 7 dispatched briefing agents to hard-STOP in one session and 10 historical PRs to need manual provenance backfill. Second, three confirmed instances (#294→#293, #298→#297, #288→#287) of a `plan/*` PR's `Closes #N` prematurely closing a task Issue when the plan merged, before the task itself ever ran.
- **Post-merge Archivist job.** `.github/workflows/archivist.yml::post-merge` (`packages/aeg-core/bin/archive-task.ts`) now runs on every push to `main`, resolves the merge commit's PR, and — for task-branch PRs only — assembles and posts the Archivist provenance block and explicitly closes the task's Issue (D-056), confirming the closed state. Idempotent per PR (an Issue can legitimately accrue multiple merged PRs over its life); skips non-task branches; fails loud on any `gh`/permission error rather than swallowing it.
- **Plan-PR Closes guard.** `bin/verify-brief.ts` now fails CI for any `plan/*` branch whose PR body carries `Closes #N`, ahead of the existing non-task bypass — a plan PR creates Issues, it does not resolve one.
- **Ratifies D-077** (Type 2, Lock: YES — load-bearing lifecycle mechanics; changing either gate requires a superseding decision).
- **Deliberately out of scope.** The Iteration Archivist (`roles/iteration-archivist.md`, D-050) is untouched — still Principal-dispatched, forge-agnostic, not a GitHub Action. Items 2–7 of per-task close-out (decision-log presence, docs coherence, per-project state, `docs-index.md`, token ledger) remain dispatched-Archivist judgment work; the automated job surfaces DANGLING markers, it does not perform judgment. No retroactive re-archival of historical PRs already manually backfilled.
